# goodfriend

be a goodfriend and remember your friends' birthdays.

[![watch the goodfriend mod](https://raw.githubusercontent.com/nicodunks/goodfriend-demo/main/media/poster.jpg)](https://github.com/nicodunks/goodfriend-demo/blob/main/media/goodfriend.mp4)

A Claude Code mod. While Claude works, the spinner gives you heads-ups ("🎂 Leo's birthday is in 3 days"). On the day, a card pops up and one tap opens Messages with a happy birthday ready to send.

## Install

```
claude plugin marketplace add nicodunks/goodfriend && claude plugin install goodfriend@goodfriend
```

Restart Claude, then run `/seed` to add birthdays for the people you text most. macOS only, Claude Code 2.1.286+.

## Use

- `/seed`: fill in birthdays for the people who matter
- `/goodfriend`: see everyone's birthday
- `/goodfriend add Maya Chen 10/7`: add one (or just tell Claude)

Birthdays also come from Contacts. goodfriend sees who you talk to, never what you said, and keeps birthdays on your Mac.
